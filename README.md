# Claude Google Multi

A private, single-owner tool that lets the owner's own Claude desktop app work with the owner's own Google accounts (Gmail, Drive, Calendar, Docs, Sheets, Tasks, Contacts).

- Used only by its owner. It is not offered to anyone else.
- Runs on the owner's own computer. There is no server and no website.
- Google data is read and changed only when the owner asks Claude to do so.
