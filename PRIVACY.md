# Privacy Policy — Claude Google Multi

Last updated: 2026-10-28

Claude Google Multi is a personal tool used only by its owner, with the owner's own Google accounts.

## What it accesses

With the owner's permission, it can read and change data in the owner's Google accounts: Gmail, Google Drive, Google Calendar, Google Docs, Google Sheets, Google Tasks and Google Contacts.

## How the data is used

- Data is accessed only when the owner asks Claude to do a task, and only for that task.
- Sign-in tokens are stored only on the owner's own computer.
- No data is sold, shared with third parties, or used for advertising.
- There is no server operated for this tool. It does not collect data from anyone other than the owner.

## Google API Services User Data Policy

Use of information received from Google APIs adheres to the [Google API Services User Data Policy](https://developers.google.com/terms/api-services-user-data-policy), including the Limited Use requirements.

## Removing access

The owner can remove access at any time at https://myaccount.google.com/permissions.
